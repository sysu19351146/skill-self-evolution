# 图1：按增量价值分配Skill职责

对应正文开篇。建议输出：`assets/01-model-skill-boundary-whiteboard.png`。这是当前脚本配图的可选手绘版本，内容与实际配图保持一致。

生成一张"专家白板教学"风格的手绘信息图，主题：按增量价值分配Skill职责——每条规则都有收益、成本和适用条件，横版16:9，背景为干净白色白板。

**视觉元素：** 使用真实马克笔手绘质感的粗细不均线条和圆角方框。上方三个职责区，下方三个判断条件。蓝色表示通用指导，绿色表示稳定操作，橙色表示当前事实与证据。这是分类比较，不画职责区之间的替代箭头。

**画面左上：** 蓝色圆角方框，内画简笔画大脑图标，标题“通用分析指导”，三行说明“任务拆解、计划、自我检查”“模型已能稳定完成时”“尝试减少固定步骤”。

**画面上中：** 绿色圆角方框，内画简笔画工具箱图标，标题“稳定的重复操作”，说明“读取环境、构建、执行测试”“操作稳定且反复发生时”“整合为可检查的脚本”。

**画面右上：** 橙色圆角方框，内画简笔画文件与试管图标，标题“当前事实与交付证据”，说明“需求、源码、实际运行结果”“通过读取与执行获取”“相关条件变化后重新确认”。不画模型凭推理直接生成通过证据。

**画面中部：** 写“分析方法可以调整；交付要求由任务目标决定”。下方写“对每条规则，同时检查三个条件”。

**画面下方：** 三个浅绿色圆角方框，分别内画简笔画天平、时钟和地图图标。标题为“收益”“成本”“适用范围”；对应说明为“改善结果，或减少失败与返工”“推理、工具往返与维护投入”“模型、任务、环境与退出条件”。三框不连箭头，避免表达时间顺序。

**画面右下角：** 在内容区之外预留空白，画一个简笔画火柴人老师拿着马克笔指向适用范围框，气泡写“条件变了，规则也要复评！”

**文字：** 全部用清晰可辨的真实手写风格。大标题“按增量价值，重新分配Skill的职责”，副标题“按收益、成本与适用条件，调整模型和Skill各自承担的工作”。底部写“收益判断 + 成本核算 + 适用条件 = 可复评的规则”。

**内容结构：** 上方解释不同内容如何处理，下方解释每条规则如何接受检验。不画能力百分比、训练时间线或具体规则的虚构收益。留白30%以上，整体干净、专业、像课堂白板教学图，所有文字必须100%清晰可读，无模糊、无重叠，高对比度。

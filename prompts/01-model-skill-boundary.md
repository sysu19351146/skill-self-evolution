# 图1：模型能力变化与Skill职责调整

对应正文：开篇中模型能力变化与Skill职责划分的讨论。建议输出文件：`assets/01-model-skill-boundary-whiteboard.png`。这是一张机制示意图，不表示已测出具体模型内化了哪些流程。

生成一张"专家白板教学"风格的手绘信息图，主题：模型学会流程以后，Skill怎样调整职责——减少重复指导，补充当前任务仍需要的外部支持，横版16:9，背景为干净白色白板。

**视觉元素：** 使用真实马克笔手绘质感的粗细不均线条、箭头和圆角方框。上半部分左右对照，下半部分是短流水线。蓝色代表模型可学习的通用方法，绿色代表必要外部支持，橙色标记需要重新评估的流程。图中文字全部使用中文，不画模型能力百分比或虚构的训练阶段。

**画面左上：** 蓝色圆角方框，内画简笔画大脑与书本图标，标题“模型可逐步内化”，内部三行短字“通用推理”“自我检查”“策略调整”。方框下方附一张橙色便签，内画简笔画重复文档图标，标注“检查旧流程是否仍有增量价值”。用橙色实线箭头从蓝框指向便签，标注“能力变化后复评”。

**画面右上：** 绿色圆角方框，内画简笔画工具箱与文件夹图标，标题“仍需外部支持”，内部三行短字“当前项目事实”“配套执行脚本”“交付约束与验证”。下方小字“会验证，仍要运行才知道是否通过”。左右上方框之间不画替代箭头，避免表达模型可以代替真实运行。

**画面左下：** 浅蓝色圆角方框，内画简笔画天平图标，标题“复测当前模型”，小字“基线与现行方法”。右侧橙色圆角方框，内画简笔画放大镜图标，标题“识别冗余与缺口”，小字“检查实际执行”。两框用粗蓝色实线箭头连接，标注“运行反馈”。

**画面中下：** 绿色圆角方框，内画简笔画剪刀与扳手图标，标题“调整外部方法”，小字“精简流程、整合脚本、补强约束”。从识别冗余与缺口画粗橙色实线箭头指向此框，标注“定向修改”。再向右侧深绿色圆角方框画粗绿色实线箭头，标注“比较效果”。深绿色框内画简笔画带对勾的清单图标，标题“检验候选版本”，小字“质量与执行开销”。从深绿色框沿下方画绿色虚线箭头返回复测当前模型，标注“模型更新或出现新问题时复评”。

**画面右下角：** 在流水线之外预留空白，画一个简笔画火柴人老师拿着马克笔指向左上橙色便签，旁边画一个对话气泡写“模型进步了，流程也要复评！”

**文字：** 全部用真实手写风格，清晰可辨。标题大而醒目“模型学会以后，外部流程重新证明价值”，副标题“通用方法逐步内化，当前事实与交付证据仍需获取”。底部写“模型能力 + 必要外部支持 + 持续复评 = 动态调整的工作方法”。

**内容结构：** 上方对照模型能力与必要外部支持，下方解释人工与模型协同复评的方法路径。所有箭头有关系文字，虚线表示由能力变化或新问题触发的后续复评，实线表示当前流程。留白30%以上，整体干净、专业、像课堂白板教学图，所有文字必须100%清晰可读，无模糊、无重叠，高对比度。
